الحل الأول: استخدام إضافة متصفح (الأسهل والأسرع) موصى به

قم بتثبيت إضافة متصفح تقوم بفك حظر الـ CORS تلقائياً أثناء وجودك على كمبيوترك:

  • ثبّت إضافة "Allow CORS: Access-Control-Allow-Origin" لمتصفح Chrome أو Edge.
  • قم بتفعيل الإضافة (إضاءة الأيقونة باللون الأخضر).
  • اعمل إعادة تحميل لهذه الصفحة وستعمل عملية جلب الوزن فوراً.
الحل الثاني: تشغيل Chrome بوضع تعطيل حظر الأمان

يمكنك فتح متصفح Chrome عبر موجه الأوامر (CMD / Terminal) مع إيقاف فحص CORS بنفس الجلسة:

chrome.exe --disable-web-security --user-data-dir="C:/temp-chrome"
الحل الثالث: تشغيل وسيط محلي (Local Proxy Script)

إذا أردت حلاً دائماً مستقلاً، يمكنك تشغيل هذا السكربت البسيط بلغة Python على جهازك ليعمل كـ Proxy محلي يعيد إرسال جلسة الدخول دون قيود: 

from flask import Flask, request, jsonify
import requests

app = Flask(__name__)

@app.route('/get-weight')
def get_weight():
    # استبدل بالرابط الحقيقي للقبان
    res = requests.get('YOUR_SCALE_API_URL', cookies=request.cookies)
    return (res.text, res.status_code, {'Access-Control-Allow-Origin': '*'})

app.run(port=5000)
